Seconds or milliseconds?

Unix time traditionally counts seconds since 00:00:00 UTC on 1 January 1970. JavaScript and many browser APIs use milliseconds instead. A current timestamp therefore usually has about ten digits in seconds and thirteen digits in milliseconds.

The converter can detect the likely unit automatically, but you can select it explicitly when working with older or unusual dates. A datetime-local value is interpreted in the timezone configured in your browser, then also shown as UTC.
