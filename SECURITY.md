# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue.

Use GitHub private vulnerability reporting for this repository:

https://github.com/lepczynski-cloud/admin-toolkit/security/advisories/new

Include:

- the affected URL or file,
- clear reproduction steps,
- the expected and observed behaviour,
- the potential impact,
- any suggested remediation.

Please allow reasonable time for investigation and remediation before public disclosure.

## Scope

The supported version is the current deployment from the `main` branch at:

https://admintoolkit.lepczynski.it/

The project is a static client-side application. It does not intentionally collect credentials, personal information or calculator input.
