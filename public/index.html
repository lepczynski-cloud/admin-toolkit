Built for administrators

Practical answers without sending your data anywhere.

Admin Toolkit is a static collection of small utilities for everyday Linux, network and DevOps tasks. There is no account system, application backend or telemetry.

⌁
Runs locally

Inputs are processed by JavaScript on your device instead of an API.

◌
Works offline

The installable PWA caches the site after a successful visit.

A separate hardware project

Admin Toolkit, now on an ESP32 touchscreen.

This website is the browser-based version. I also built a separate offline-first toolkit for the Elecrow CrowPanel 2.8-inch ESP32 with eight touch-friendly tools, including Wi-Fi and BLE scanning, CIDR, VLSM and cron.

The ESP32 project has its own website with a device demo, source code and a browser installer for the latest successfully built firmware. No local PlatformIO or IDE setup is needed to flash the supported device.
