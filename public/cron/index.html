Meaning

Standard Unix cron format

This generator uses the common five-field format: minute, hour, day of month, month and day of week. The expression 0 8 * * 1-5 runs at 08:00 from Monday through Friday.

The actual execution time depends on the timezone configured on the machine or container running the cron daemon. Public holidays are not automatically excluded, and jobs scheduled on day 29, 30 or 31 will not run in months that lack that date.

Not every scheduler uses the same syntax

Quartz, AWS EventBridge, Kubernetes CronJobs and other platforms can add fields or use different day-of-week rules. Treat the result here as standard Unix cron and verify it against the documentation for the target system.
